## Справочники

### Справочник 1 — Страны (`countries`)

| Колонка             | Тип PostgreSQL  | Тип данных        | Описание                         |
|---------------------|-----------------|-------------------|----------------------------------|
| `id`                | SERIAL          | целое, PK         | Первичный ключ                   |
| `name`              | VARCHAR(200)    | текст             | Название страны                  |
| `continent`         | VARCHAR(100)    | текст             | Континент                        |
| `population`        | INTEGER         | целое число       | Население (человек)              |
| `area`              | DECIMAL(14,2)   | дробное число     | Площадь (км²)                    |
| `independence_date` | DATE            | дата              | Дата объявления независимости    |
| `notes`             | TEXT            | многострочный текст | Произвольные примечания        |
| `is_deleted`        | BOOLEAN         | флаг              | Мягкое удаление (soft delete)    |
| `created_at`        | TIMESTAMP       | дата/время        | Дата создания записи             |
| `updated_at`        | TIMESTAMP       | дата/время        | Дата последнего изменения        |

### Справочник 2 — Города (`cities`)

| Колонка        | Тип PostgreSQL | Тип данных        | Описание                            |
|----------------|----------------|-------------------|-------------------------------------|
| `id`           | SERIAL         | целое, PK         | Первичный ключ                      |
| `name`         | VARCHAR(200)   | текст             | Название города                     |
| `country_id`   | INTEGER        | целое, FK         | **Ссылка на `countries.id`**        |
| `description`  | TEXT           | многострочный текст | Описание города                  |
| `population`   | INTEGER        | целое число       | Население (человек)                 |
| `area`         | DECIMAL(12,2)  | дробное число     | Площадь (км²)                       |
| `founded_date` | DATE           | дата              | Дата основания                      |
| `is_deleted`   | BOOLEAN        | флаг              | Мягкое удаление                     |
| `created_at`   | TIMESTAMP       | дата/время       | Дата создания записи                |
| `updated_at`   | TIMESTAMP       | дата/время       | Дата последнего изменения           |

**Зависимость справочников:** в справочнике *Города* поле `country_id` является
внешним ключом (FOREIGN KEY) на `countries.id`. Таким образом, каждый город принадлежит
определённой стране из первого справочника.

**Типы данных** присутствуют во **всех** требуемых категориях:
- текст: `name`, `continent`, `notes`, `description`
- дата: `independence_date`, `founded_date`
- целое число: `population`
- дробное число: `area`
